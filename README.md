<h2 align="center">📌 About Me</h2>

Hi, I'm Akira Saskara Hartono, a Junior Full Stack Developer and Software Engineering student at SMK Telkom Malang. I enjoy building web applications from end to end, turning ideas into products that are functional, scalable, and easy to use.

My experience spans both frontend and backend development using technologies such as React.js, Next.js, TypeScript, PHP, NestJS, PostgreSQL, and Prisma ORM. I also work with tools like Docker, GitHub, Railway, Vercel, and GitHub Actions, and I'm comfortable collaborating in team environments using Git-based workflows. I enjoy learning new technologies and solving technical challenges through a structured and practical approach.

One of the projects I'm most proud of is MEXPO, where I served as the Frontend Lead, developing a Next.js-based event platform featuring QR code registration and real-time event information. I also contributed as a Backend Developer for Nusabite, building secure REST APIs with NestJS, PostgreSQL, Prisma, JWT Authentication, Swagger, and CI/CD pipelines, as well as Glucofy, a health application focused on scalable backend services.

I'm always open to internship opportunities, collaborative projects, and connecting with people who are passionate about software engineering, backend development, and building impactful digital products.
